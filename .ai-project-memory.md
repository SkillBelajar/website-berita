# Memori Proyek: Portal Berita Kepatuhan PPMS (website-berita)

## 1. 5W+1H Visi Aplikasi
- **What**: Portal Berita Digital modern dengan kepatuhan penuh terhadap Pedoman Pemberitaan Media Siber (PPMS) Dewan Pers, arsitektur microservice/containerized, dan sistem auditabilitas konten pers.
- **Who**: 
  - **Superadmin**: Manajemen sistem, konfigurasi, audit log, dan tata kelola akun.
  - **Editor**: Kurasi berita, approval naskah dari jurnalis, penerbitan log ralat, dan penanganan hak jawab.
  - **Journalist**: Penulisan draf berita, pengajuan liputan, dan revisi naskah.
  - **Verified User**: Pembaca terverifikasi yang memiliki hak partisipasi UGC (komentar) dan pengajuan hak jawab.
  - **Public**: Pembaca berita umum tanpa autentikasi.
- **Why**: Menjawab tantangan disinformasi, mematuhi regulasi Dewan Pers (PPMS), mengelola risiko hukum dari *User Generated Content* (UGC), dan menyediakan mekanisme transparan untuk hak jawab dan pencabutan/ralat berita.
- **Where**: Arsitektur Full Docker:
  - Backend: Go (Golang) REST API (Container port 8080, Host port 8383)
  - Frontend: Next.js (React) + Tailwind CSS (Container port 3000, Host port 3001)
  - Database: PostgreSQL 15 (Container port 5432, Host port 54321)
  - Cache & Message Broker: Redis 7 (Container port 6379, Host port 63821)
- **When**: Siklus penerbitan berita real-time, moderasi komentar otomatis sebelum tayang, dan penanganan sengketa pers/hak jawab berbatas waktu sesuai standar etika jurnalistik.
- **How**: 
  - Alur editorial ketat (*two-tier publishing*: Wartawan menulis draf -> Editor memeriksa, menyunting, dan menerbitkan).
  - Filter otomatis kata terlarang/SARA/hoaks pada UGC (kolom komentar) dengan antrean moderasi.
  - Fitur Log Ralat Tersemat (*Embedded Correction Log*) yang secara permanen mencatat waktu dan detail ralat pada berita yang telah tayang.
  - Fitur Hak Jawab Terintegrasi yang menautkan langsung tanggapan pihak terkait ke artikel sumber.

## 3. Rancangan API Blueprint

### A. Autentikasi & Akun (`/api/v1/auth`)
- `POST /api/v1/auth/register` - Pendaftaran akun publik/terverifikasi
- `POST /api/v1/auth/login` - Otentikasi user & pengembalian token JWT
- `POST /api/v1/auth/logout` - Revokasi token sesi
- `GET  /api/v1/auth/me` - Ambil profil pengguna login
- `POST /api/v1/auth/refresh` - Refresh access token

### B. Konten Publik (`/api/v1/articles`, `/api/v1/categories`, `/api/v1/tags`)
- `GET  /api/v1/articles` - Daftar berita publik (filter kategori, tag, search, pagination)
- `GET  /api/v1/articles/:slug` - Detail artikel lengkap (termasuk log ralat tersemat & tautan hak jawab jika ada)
- `GET  /api/v1/categories` - Daftar kategori berita
- `GET  /api/v1/tags` - Daftar tag populer

### C. Alur Kerja Editorial (`/api/v1/editor/articles`)
- `GET    /api/v1/editor/articles` - Daftar draf naskah (status: draft, review, published, rejected)
- `POST   /api/v1/editor/articles` - Buat naskah berita baru (Journalist/Editor)
- `GET    /api/v1/editor/articles/:id` - Detail naskah editorial
- `PUT    /api/v1/editor/articles/:id` - Perbarui isi draf berita
- `DELETE /api/v1/editor/articles/:id` - Hapus draf naskah
- `POST   /api/v1/editor/articles/:id/publish` - Publikasikan artikel (Role: Editor/Superadmin)
- `POST   /api/v1/editor/articles/:id/reject` - Kembalikan draf dengan catatan revisi

### D. UGC & Moderasi Komentar (`/api/v1/articles/:id/comments`, `/api/v1/moderation`)
- `GET  /api/v1/articles/:id/comments` - Daftar komentar tayang (hanya yang lolos moderasi)
- `POST /api/v1/articles/:id/comments` - Kirim komentar (wajib login, difilter otomatis oleh sistem kata terlarang)
- `GET  /api/v1/moderation/comments` - Antrean komentar pending / terindikasi pelanggaran
- `PUT  /api/v1/moderation/comments/:id/approve` - Setujui komentar secara manual
- `PUT  /api/v1/moderation/comments/:id/reject` - Tolak / hapus komentar melanggar

### E. Kepatuhan PPMS (Dewan Pers) (`/api/v1/ppms`)
- `POST /api/v1/ppms/articles/:id/corrections` - Tambahkan log ralat tersemat pada artikel tayang
- `GET  /api/v1/ppms/articles/:id/corrections` - Riwayat catatan ralat artikel
- `POST /api/v1/ppms/right-of-reply` - Form pengajuan hak jawab oleh publik/pihak terkait
- `GET  /api/v1/ppms/right-of-reply` - Daftar antrean pengajuan hak jawab untuk editor
- `PUT  /api/v1/ppms/right-of-reply/:id/link` - Editor mengaitkan hak jawab yang disetujui ke artikel sumber
